# `course-2026` becomes the default branch for the semester

For the 2026–27 *Complex Web Services* course, about twenty students fork OcéEns and fork its default branch. `course-2026` therefore becomes the repository's default branch: forks start from it and pull requests target it (including the dev login, #82, and the per-role seed, #84). `main` is left untouched during the semester, to give students a stable base and keep course-specific code out of it; no `main` → `course-2026` sync is planned before the end of the semester.
